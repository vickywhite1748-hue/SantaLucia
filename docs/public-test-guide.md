# 《桑塔露琪亚》公开测试版使用说明

本文档给公开测试人员使用，说明如何进入测试版、怎样使用调试功能，以及反馈问题时需要提供哪些信息。

## 测试入口

公开测试版入口：

<https://vickywhite1748-hue.github.io/SantaLucia/test/>

正式版入口：

<https://vickywhite1748-hue.github.io/SantaLucia/>

测试版只在约定测试时段开放，时间按香港时间计算。非开放时段进入测试入口时，会看到关闭提示。

![测试入口关闭状态](images/test-gate-closed.png)

开放时段内，测试入口会自动跳转到测试游戏页。如果没有自动跳转，可以点击“进入测试版”。

![测试版游戏首页](images/test-game-home.png)

## 开始前检查

进入测试版后，先确认首页右上角显示：

- 版本号：`v0.2.0`
- 节点数量：`175 个节点`
- 右下角校验提示无错误

如果页面仍显示“测试入口已关闭”，说明当前不在开放时段，或浏览器缓存还没有刷新。可以先刷新页面；如果仍然关闭，请改用正式版入口或等待测试时段。

## 推荐测试流程

1. 点击“开始新故事”，从开头完整体验一条路线。
2. 遇到选项时，记录你选择的大意，尤其是影响人物关系、离家、隐瞒、救援、传记改写的选择。
3. 如果发现文字不通顺、选项无法点击、剧情接不上、跳转到奇怪段落，先不要清除记录，直接反馈当前位置。
4. 完成一条路线后，可以回到首页，使用“选择章节”或“重新开始”测试其他路线。
5. 测试结束后，如需排查旧存档影响，可以在首页菜单使用“清除记录”。

## 调试模式

公开测试版保留调试查看功能，方便定位问题，但不开放编辑模式。

### 进入调试模式

有两种进入方式：

1. 在游戏首页点击“设置”，找到“调试模式”，选择“开启”。
2. 进入剧情后，点击右下角“☰”菜单，再点击“调试模式”。

开启后，页面会出现“调试模式”面板。面板可以“最小化”或“关闭”；关闭面板不等于关闭调试模式，只是隐藏面板。需要再次打开时，可再点右下角“☰”菜单里的“调试模式”。

可用功能：

- 查看当前节点 ID、节点类型、父节点、子节点。
- 查看当前选项、路由命中情况、数值和 flags。
- 输入节点 ID 后跳转到指定节点。
- 点击“复制状态”，把当前节点、数值、flags、路由等调试信息复制出来。
- 勾选“显示流程节点”，在节点列表里显示路由和逻辑判断节点。

### 节点跳转

节点跳转用于快速复现某一段剧情，不建议在第一次完整体验时频繁使用。

操作步骤：

1. 先开启调试模式。
2. 在调试面板顶部的输入框中输入节点 ID，或从下拉列表选择节点。
3. 点击“跳转”。
4. 页面会直接进入该节点；如果节点 ID 不存在，会出现“节点不存在”的提示。

节点 ID 通常长这样：`s15_rose_scold`、`s26_departure_open`、`s_final_route_logic`。如果你不确定要跳到哪里，可以先在当前问题页面点击“复制状态”，把内容发给维护者，由维护者判断应该跳转到哪个节点。

勾选“显示流程节点”后，下拉列表会包含更多路由和逻辑判断节点。这些节点常用于排查分支条件是否命中；普通测试人员一般只需要跳转到剧情节点。

### 复制调试状态

反馈剧情流程问题时，请优先点击“复制状态”，并把复制出的内容贴到反馈里。它通常包含：

- 当前节点 ID。
- 当前数值和 flags。
- 当前节点可见选项。
- 路由条件和命中情况。

这些信息比单独截图更适合排查“为什么跳到这里”。

不可用功能：

- 编辑当前节点。
- 导出测试 JSON。
- 清除或保存浏览器里的测试修改副本。

如果要反馈剧情流程问题，优先提供“复制状态”的内容。

## 反馈入口

游戏页面里有常驻“反馈”按钮。测试时如果遇到文本、选项、跳转、存档或页面显示问题，优先用这个入口反馈。

操作步骤：

1. 停在出现问题的页面，不要先清除记录。
2. 点击页面里的“反馈”。
3. 弹窗会打开腾讯问卷，并自动复制当前版本、页面来源、节点、进度和调试上下文。
4. 在问卷的“自动反馈信息”里粘贴复制内容，再补充问题描述。
5. 如果浏览器没有自动复制，可以点击“复制自动信息”；如果需要检查复制内容，可以点击“显示自动信息”展开查看。

自动信息默认隐藏，是为了不遮挡问卷。剧情流程、选项跳转、routes、flags 等问题仍建议先在调试面板点击“复制状态”，再一并粘贴到问卷里。

## 反馈格式

问卷中请尽量写清楚：

```text
测试入口：公开测试版 / 正式版
设备和浏览器：例如 Windows Chrome / iPhone Safari
大概时间：例如 2026-05-19 15:20 香港时间
当前节点 ID：可由反馈入口自动复制，或从调试模式复制状态获得
问题类型：文本 / 选项 / 跳转 / 存档 / 显示 / 其他
复现步骤：
1. 从哪里开始
2. 点击了哪些选项
3. 出现了什么异常

预期结果：
实际结果：
截图、自动反馈信息或复制状态：
```

## 常见情况

- “测试入口已关闭”：不在测试开放时段，或测试页已被门禁关闭。
- 页面仍是旧内容：刷新页面，必要时使用无痕窗口重新打开。
- 继续按钮进入了旧进度：这是浏览器本地存档；可用“重新开始”或“清除记录”。
- 调试面板看不到编辑按钮：这是预期行为，公开测试版关闭编辑模式。
- 选项被底部进度条遮住：请截图并反馈设备、浏览器、当前节点 ID。
- 反馈弹窗里的自动信息框没有显示：这是预期行为；点击“显示自动信息”才会展开。
- 问卷没有自动粘贴信息：浏览器可能限制剪贴板权限，请点击“复制自动信息”后手动粘贴。
- 第二次打开反馈仍停在提交成功或红包广告页：请先关闭反馈弹窗再重新打开；如果仍不能填写，说明问卷后台可能限制了同一设备重复提交，请联系维护者调整问卷设置。

## 测试重点

本轮优先关注：

- 移动端和桌面端选项是否能正常点击。
- 进度条、底部按钮、菜单是否遮挡正文或选项。
- 反馈弹窗是否能正常打开，问卷是否能填写，自动信息是否能复制或展开。
- 分支后文是否承接前面的选择，而不是突然回到另一条路线。
- 调试模式是否能正确显示当前节点、路由、flags。
- 结局、成就、章节选择、存档槽是否能正常打开和返回。
