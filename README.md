# SantaLucia

《SantaLucia》是一个中文互动剧情游戏项目。玩家将通过阅读剧情、做出选择、进入不同分支，逐步看见角色关系、事件真相与多个可能的结局。

## 在线体验

公开网址：

https://vickywhite1748-hue.github.io/SantaLucia/

打开网页即可游玩，无需安装。

## 玩法说明

- 阅读当前剧情文本，理解角色处境与事件线索。
- 在关键节点选择不同选项，推动故事进入不同分支。
- 部分选择会影响后续剧情、角色态度和结局走向。
- 可以重新开始，尝试不同选择路径，解锁更多内容。
- 建议使用现代浏览器访问，桌面端和移动端均可体验。
