# SantaLucia

## 项目来源与致谢

本项目初期参考并引用了 [Shanyin-ai/Story-to-game](https://github.com/Shanyin-ai/Story-to-game) 的模板与基础结构，在此基础上整理、改写并制作了《桑塔露琪亚》Sonnyboy 视角的分支剧情版本。

《桑塔露琪亚》Sonnyboy 视角文游是一款关于家族、控制、离家与回头的中文分支剧情游戏。

玩家将从 Sonnyboy 被 Luciano 带回 Bocchetti 家族开始，经历他和 Chi Chi 从陌生、试探、依赖、伤害，到面对家族继承、真相、离家、救援与传记改写的完整路线。

## 玩法说明

这不是单线阅读，而是分支剧情。你的选择会影响：

- Sonnyboy 和 Chi Chi 的关系走向
- Sonnyboy 是否离开家族
- 他是否真正离开，又会以什么方式回头
- 他是亲自救人，还是继续用权力安排一切
- 最后的传记会被写成真相、谎言，还是无人署名的故事

推荐第一次凭直觉选择，不用追求最好结局。第二次可以尝试反着选，看看 Sonnyboy 的控制欲、保护欲和迟疑会把故事带到哪里。

## 内容说明

当前版本包含：

- Sonnyboy 视角主线
- 160 个节点（152 个剧情节点、8 个结局节点）
- 8 个结局
- 25 个成就
- 多条离家、留家族、救援、隐瞒、坦白路线

本版本重点优化了分支逻辑。不同选择不会只是更换几句台词，而是会尽量让后文保留它造成的后果。照片、巷口、黄玫瑰、遗言、报纸、Florence 的信，都会在不同路线里留下不同程度的影响。

这不是一个“好人做正确选择”的故事。Sonnyboy 可以保护人，也可以伤害人；他可以回头，也可能只是换一种方式继续控制。Chi Chi 也不是等待被救的人，他会依赖、反抗、沉默、逃走，也会把别人写给他的命运改掉。

如果你喜欢家族叙事、兄弟关系、黑帮背景、复杂人物、分支文字游戏和多结局剧情，可以试试看这个版本。
